# Streamlit Data Automation

## Overview

Streamlit Data Automation is a web application built with **Python and Streamlit** to automate data cleaning, validation, and processing workflows. It allows non-technical users to upload standardized datasets and apply predefined business rules through a simple and intuitive interface.

## Key Features

* Upload standardized datasets (CSV / Excel)
* Automatic data cleaning and column selection
* Business rules and data validation
* Handling missing or inconsistent values
* Export processed data files
* User-friendly web interface

## Technologies Used

* Python
* Pandas
* Streamlit

## Use Case

This project was designed to replace manual and repetitive data processing tasks, reducing errors and improving productivity. It is suitable for operational teams, analysts, and anyone who needs fast and reliable data preparation without coding.

## Project Goals

* Automate repetitive data processing tasks
* Make data automation accessible to non-technical users
* Apply business rules in a consistent and scalable way
* Deliver clean and ready-to-use datasets

## How It Works

1. Upload a standardized dataset
2. The application applies predefined cleaning and validation rules
3. Review the processed data
4. Export the final dataset

## Installation

```bash
pip install -r requirements.txt
```

## Running the App

```bash
streamlit run app.py
```
